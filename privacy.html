Privacy Policy

1. Scope and operator

Chaos Client (formerly Chaos Launcher) is an independent project maintained by YσZSHI帝. This notice describes the static website, local software and existing TikTok sandbox implementation. It does not describe an active production account service.

2. Website and launcher data

This website has no account form, payment checkout, analytics script or advertising tracker. GitHub Pages hosts it and may process technical request data, including IP addresses. The launcher stores profiles, settings, mods, worlds and logs locally. Microsoft authentication for the reviewed launcher uses Prism Launcher; Microsoft and Prism handle their respective authentication and session data. Downloads and mod search may contact GitHub, Modrinth, Minecraft/Microsoft, Fabric and Java distribution services. Those providers have their own privacy terms.

3. Optional TikTok sandbox verification

The sandbox requests user.info.basic. Its source exchanges an authorization code for an access token and reads the app-specific account identifier (open_id) and display name (display_name). A display name is not necessarily the TikTok username. The purpose is account-control verification and displaying the verification result. The source uses hashed identifiers and installation keys to check duplicate bindings; duplicate-attempt counts and warning times may be held in memory. The sandbox is designed to keep account-binding records and tokens out of persistent files, and to end the binding session when its service stops. A random installation key is stored locally. No TikTok passwords are requested by the project.

The reviewed sandbox does not request posting permissions or access to private messages, follower lists, email or phone data. Login Kit does not provide LIVE gift access. Any separate gameplay interaction integration is outside this Login Kit flow. Public production TikTok account linking is not active.

4. User control and retention

You may decline or revoke TikTok authorization in TikTok account settings. Stop the sandbox service to clear its in-memory binding session. You can remove the sandbox's local application data after making backups. Local game data remains until you delete it. A future production binding service requires documented retention limits, working unlink/deletion and a private support channel before activation.

5. Contact and rights

Use the support page for privacy questions. Do not submit personal information or tokens through public issue trackers. You may request a private contact route before sending any details. This notice does not limit rights available under applicable privacy law.

6. Changes

We will update this notice when the actual service or data practices change. No payments are processed through this website.
