Privacy Policy

This draft describes the development build and proposed TikTok integration. It must be reviewed and updated to reflect the actual deployed service, retention periods, and a private contact channel before production account linking is enabled.

Who we are

Current launcher and website

The launcher stores game profiles, settings, mods, worlds and game logs on your computer. The current Microsoft account flow is handled by a separate Prism Launcher installation; Microsoft and Prism handle authentication and its local session storage. Chaos Launcher does not operate a central Microsoft account database. This statement does not imply that Microsoft or Prism process no personal data.

The static project website does not contain its own analytics, advertising or tracking scripts or account forms. GitHub Pages hosts the website and may process technical request data such as IP addresses. The launcher makes requests to GitHub, Modrinth, Minecraft/Microsoft, Fabric and Java distribution services as needed for downloads, search, authentication or game operation; these services may receive network and request information and have their own privacy policies.

Proposed TikTok account linking (not live)

Only streamers who choose to link their TikTok account will use the proposed service. TikTok's own consent page handles login. The planned purpose is to verify account control and prevent duplicate account bindings. The draft server exchanges authorization codes for access tokens, uses an app-specific TikTok account identifier and, if separately authorized and needed, a username. The prototype stores a hashed account identifier, a hashed installation key, username, duplicate-attempt count and last warning time. Hashing does not make these records anonymous. Tokens are processed for account verification; the prototype does not persist them in its binding file. We do not intend to collect passwords, private messages, phone numbers or email addresses from TikTok.

The binding records would be kept to enforce the single-link rule. The production service is not yet deployed; retention limits, account unlinking, deletion and secure hosting must be implemented and documented before activation. The launcher will not request access to posting or LIVE gifts through Login Kit.

Control and deletion

You can manage Microsoft accounts in Prism and revoke app authorization through the relevant platform's account settings. Local launcher data can be removed from the installation's data directory; back up worlds first. Production TikTok unlinking and data deletion are not yet available because the verification service is not live.

Contact

For general privacy questions, contact the maintainer through the project issue tracker. Request a private contact channel before sharing personal data. Never post credentials, tokens, or personal information in a public issue. A private privacy contact method must be established before the production integration is enabled.

Changes

This draft will be updated before the TikTok integration is released and whenever the actual data practices change.
