LOGIN KIT · ACCOUNT CONTROL

TikTok account linking

Chaos Client is designed to offer optional creator account verification through TikTok's official authorization page. The purpose is to verify account control, not to access private messages, post videos or read LIVE gifts through Login Kit.

Authorization flow

  1. Open the Publisher section in the desktop client and choose TikTok verification.
  2. Review the requested access on TikTok's authorization page and consent or cancel.
  3. The desktop integration receives an authorization result. The sandbox implementation requests user.info.basic and reads an app-specific account identifier and display name.
Production access is not enabled. The existing sandbox integration is intended for review and testing; a successful end-to-end login has not been independently verified. No TikTok login form is hosted on this website.

Disconnect and data removal

To revoke authorization, use TikTok account settings → Security & permissions → Apps and services permissions (labels may vary), then remove access for Chaos Client. Closing the entire sandbox process ends its in-memory account session. The sandbox keeps a local random installation key; local sandbox data can be removed from its separate data directory after backing up any worlds.

For privacy questions or assistance, see Support. Before enabling a production binding database, a private contact route, documented retention limits and a verified unlink/delete process are required.
